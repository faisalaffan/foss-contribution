# Security Policy

This is a static portfolio repository — it contains no running code, APIs, or user data. There are no security risks to end users.

## Reporting a Vulnerability

If you discover a security concern (e.g., accidentally committed credentials, sensitive links, or misconfigured workflows):

1. **Do not open a public issue**
2. Send details to the repository owner via private message on GitHub

## Scope

Security concerns are limited to:

- Accidental credential exposure in this repository
- Malicious or vulnerable GitHub Actions workflow dependencies
- Sensitive information in commit history

## Supported Versions

Only the latest commit on the default branch (`dev`) is maintained.
