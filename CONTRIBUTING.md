# Contributing

This is a personal open-source portfolio. Contributions, suggestions, and corrections are welcome.

## Scope

This repository documents my open-source contributions and projects. If you find errors, outdated information, or missing context:

1. **Open an Issue** — describe what's wrong or missing
2. **Submit a Pull Request** — fix it directly

## Adding Contributions

If you're adding a new contribution entry:

- Add a row to the appropriate table (Non-Trivial or Trivial) in both `README.md` and `README.id.md`
- If it's a highlighted contribution, create a detail page in `contributions/`
- Follow the existing bilingual convention: one file in English, one in Bahasa Indonesia

## Style

- Keep descriptions concise — one line per entry
- Use sentence case for headings
- Follow the existing table format

## PR Status

PR statuses are synchronized daily via GitHub Actions (`.github/workflows/sync-pr-status.yml`). No manual status updates needed.
