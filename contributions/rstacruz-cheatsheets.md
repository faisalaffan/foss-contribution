# rstacruz/cheatsheets — Add Dart cheatsheet with Flutter quick reference

## Context

[rstacruz/cheatsheets](https://github.com/rstacruz/cheatsheets) is a community-driven collection of developer cheatsheets. It lacked a Dart cheatsheet — three open issues (#264, #1646, #1790) requested one, collectively accumulating significant community interest.

## Contribution

Created a comprehensive Dart 3.x cheatsheet covering:
- Dart basics — variables, types, functions, control flow
- Null safety — `?`, `!`, `late`, `required`
- Records, patterns, and destructuring
- Sealed classes and enhanced enums
- Flutter essentials — widgets, layout, styling, navigation, state management

## Impact

- 1,425 lines of new reference content
- Resolves 3 long-standing open issues (#264, #1646, #1790)
- First Dart cheatsheet in the repository
