# rstacruz/cheatsheets — Tambah Dart cheatsheet dengan Flutter quick reference

## Konteks

[rstacruz/cheatsheets](https://github.com/rstacruz/cheatsheets) adalah koleksi cheatsheet developer yang digerakkan oleh komunitas. Repositori ini belum memiliki cheatsheet Dart — tiga issue terbuka (#264, #1646, #1790) memintanya, dengan minat komunitas yang signifikan.

## Kontribusi

Membuat cheatsheet Dart 3.x komprehensif yang mencakup:
- Dasar-dasar Dart — variabel, tipe, fungsi, control flow
- Null safety — `?`, `!`, `late`, `required`
- Records, patterns, dan destructuring
- Sealed classes dan enhanced enums
- Flutter essentials — widgets, layout, styling, navigation, state management
