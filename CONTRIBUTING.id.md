# Berkontribusi

Ini adalah portfolio open-source pribadi. Kontribusi, saran, dan koreksi sangat diterima.

## Cakupan

Repositori ini mendokumentasikan kontribusi open-source dan proyek saya. Jika Anda menemukan error, informasi usang, atau konteks yang kurang:

1. **Buka Issue** — jelaskan apa yang salah atau kurang
2. **Submit Pull Request** — perbaiki langsung

## Menambahkan Kontribusi

Jika Anda menambahkan entri kontribusi baru:

- Tambahkan baris ke tabel yang sesuai (Non-Trivial atau Trivial) di `README.md` dan `README.id.md`
- Jika kontribusi yang ditonjolkan, buat halaman detail di `contributions/`
- Ikuti konvensi bilingual: satu file Bahasa Inggris, satu Bahasa Indonesia

## Gaya

- Deskripsi singkat — satu baris per entri
- Gunakan sentence case untuk judul
- Ikuti format tabel yang sudah ada

## Status PR

Status PR disinkronkan setiap hari melalui GitHub Actions (`.github/workflows/sync-pr-status.yml`). Tidak perlu update status manual.
